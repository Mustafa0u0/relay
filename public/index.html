Open this page in a second window and type in both. The server holds the operations and passes them on; it has no idea it is moving text. Cut the wire, keep typing in both windows, then reconnect — each side is sent only what it missed, not the document.

Each character carries the two it was typed between, so an edit lands where its author meant it to however late it arrives. The server keeps an append-only log per room and a version map per author — which is all it needs to work out what a returning client missed, without either side listing what it already has.
